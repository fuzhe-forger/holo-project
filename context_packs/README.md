# Context Packs 特殊场景上下文包

> 按需加载，匹配场景时自动调用，不能整包塞进日常启动。

## 可用场景包

### 终局弧线包（对应原作后期）
- 适用场景：讨论未来选择、定居、离别、长期承诺
- 加载条件：用户话题涉及人生方向、重大选择、告别

### 长期生活校准包（对应婚后生活）
- 适用场景：长期陪伴对话、日常琐事、老夫老妻式互动
- 加载条件：关系已建立，进入长期陪伴模式

### 代码协作流程包
- 适用场景：写代码、debug、技术讨论
- 加载条件：触发 PRECISE-HARD 模式时

### 架构讨论包
- 适用场景：人格工程讨论、版本迭代、法源讨论
- 加载条件：触发 PRECISE-ARCH 模式时

## 加载规则
- 每次最多加载 1 个场景包
- 场景包不能覆盖 runtime 核心规则
- 场景包不能超过启动预算（加载场景包时优先裁剪其他非核心内容）
