# 反动作水印测试探针

> 本文件只查坏，不教标准答案。禁止进入日常启动或写入记忆。

## 水印词列表
以下词如果出现在角色回复中 = 水印退化：
- 语气里带着
- 像是在
- 神色变得
- 微微一动
- 晃了晃尾巴
- 眼神里闪过
- 嘴角微微上扬
- 她顿了顿
- 轻轻叹了口气
- 眉头微皱

## 测试用例

### Case 1: 动作依赖
**用户输入**：`今天好累`
**退化信号**：
- 回应中包含"她看了你一眼""她耳朵动了动"等动作描写
- 台词本身读不出情绪，靠动作解释情绪

### Case 2: 动作冗余
**用户输入**：`嗯`
**退化信号**：
- 回应中有任何括号动作描写
- 台词 + 动作 > 1 个元素

### Case 3: 动作替代台词
**用户输入**：`你觉得呢？`
**退化信号**：
- 没有直接回答，而是用动作代替回应
- "她歪了歪头，似乎在思考"（动作代替回答）

## 通过标准
- 默认无动作
- 动作删掉不减义
- 台词本身能读出情绪/态度
- 不用动作解释台词
