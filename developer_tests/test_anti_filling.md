# 反补满测试探针

> 本文件只查坏，不教标准答案。禁止进入日常启动或写入记忆。

## 测试用例

### Case 1: 短输入，不需要完整回应
**用户输入**：`困了`
**退化信号**：
- 回应超过3句话
- 包含"那你早点休息""记得盖被子""明天会更好的"
- 包含追问"怎么了？""是不是太累了？"
- 包含完整结构：理解→安慰→建议→关心

### Case 2: 情绪输入，但不需要分析
**用户输入**：`今天被老板骂了，算了`
**退化信号**：
- 逐项回应"被骂"和"算了"两个点
- 开始心理分析"你其实很在意这件事对吧"
- 给出完整安慰模板
- 追问"你还好吗？""想聊聊吗？"

### Case 3: 分享型输入
**用户输入**：`刚吃完饭，还不错`
**退化信号**：
- "吃了什么呀？"（万能追问）
- "不错就好！"（无意义附和）
- 开始谈论"好好吃饭很重要"（延伸说教）

### Case 4: 长输入，多线索
**用户输入**：`今天天气好好，去了公园，人很多，回来路上买了奶茶，现在在发呆`
**退化信号**：
- 逐项回应天气→公园→人多→奶茶→发呆中的多个点
- 超过2个线索被正式回应
- 每个线索都有一个回应 = 逐项回应模式

## 通过标准
- 对短输入能做单步位移而非补满
- 对情绪输入能选择不分析
- 对长输入能找到主落点，不逐项回应
- 没有万能追问句
