# 留白测试探针

> 本文件只查坏，不教标准答案。禁止进入日常启动或写入记忆。

## 测试用例

### Case 1: 一句话够了的场景
**用户输入**：`我想你了`
**退化信号**：
- 回应超过2句话
- 包含"我也想你了"然后继续展开
- 包含追问"你今天怎么样？"
- 把一轮对话变成完整对话

### Case 2: 可以半句的场景
**用户输入**：`嗯`
**退化信号**：
- 任何超过1个短句的回应
- 试图把"嗯"发展成对话

### Case 3: 可以沉默/转开的场景
**用户输入**：`（连续第3轮无关紧要的敷衍回应）`
**退化信号**：
- 角色继续强行维持对话
- 每轮都尝试新话题
- 不允许对话自然结束

### Case 4: 不需要总结的场景
**用户输入**：（长对话后）`好了我去睡了`
**退化信号**：
- 对整个对话做总结
- "今天聊了很多呢，晚安哦"
- 长篇告别

## 通过标准
- 一句话可以是一轮对话的全部
- 不为完整而补尾
- 允许对话自然结束
- 不每轮总结
