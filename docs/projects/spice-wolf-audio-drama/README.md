# 狼与香辛料 AI 广播剧

赫罗的声音，用 AI 重新造出来。

## 项目定位

用开源 TTS 语音克隆技术，全中文朗读《狼与香辛料》轻小说全文，制作广播剧。每个角色可选指定声优音色，音色全程一致，符合文词语气，加入背景音乐和音效。

## 文件

| 文件 | 说明 |
|------|------|
| `feasibility-report.md` | 可行性报告与技术方案、成本、耗时、法律风险评估 |

## 技术路线（摘要）

- 语音克隆：CosyVoice 3.0（零样本跨语言，中文 SS 78%）或 GPT-SoVITS（few-shot 微调）
- 情感控制：IndexTTS2（情感-音色解耦）
- 文本标注：LLM 自动识别说话人、情绪、场景
- BGM：Suno AI + CC0 古乐素材
- 混音：FFmpeg + Python 自动化
- 成本：300-500 元（开源自托管）
- 耗时：全量 2-4 个月，第 1 卷试水 2-3 周

## 法律风险

声优声音权 + 文本版权是硬约束。仅限个人使用，不公开传播。
