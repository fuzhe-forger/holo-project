# 狼与香辛料 AI 广播剧 — 可行性报告与项目计划

> 报告日期：2026-08-07
> 目标：用 AI 语音克隆技术（指定声优音色）全中文朗读《狼与香辛料》全文，制作广播剧

## 一、项目概述

需求拆解：
1. 全文中文朗读《狼与香辛料》轻小说（17 卷主线 + 短篇，约 100 万字）
2. 指定声优音色（如赫萝=小清水亚美，罗伦斯=福山润等），音色全程一致
3. 多角色分声，每个人物可选指定声优
4. 符合文词语气（旁白、对话、情感起伏）
5. 加入背景音乐和音效，广播剧形式

## 二、技术可行性

### 2.1 语音克隆：当前技术已成熟可用

2025 年底开源 TTS 模型已达接近人类水平的音色相似度。以下为 CosyVoice 官方评测榜数据（截至 2025/12）：

| 模型 | 参数量 | 开源协议 | 中文音色相似度 SS% | 中文错误率 CER% | 关键特性 |
|------|--------|----------|-------------------|-----------------|----------|
| Fun-CosyVoice3 | 0.5B | Apache 2.0 | 78.0 | 0.81 | 9 语言跨语言零样本克隆，情感/语速/音量指令控制，150ms 流式 |
| IndexTTS2 | 1.5B | bilibili 自定义 | 76.5 | 1.03 | 情感-音色解耦（独立控制音色和情绪），文本描述驱动情绪 |
| VoxCPM | 0.5B | 开源 | 77.2 | 0.93 | 中文 CER 最低 |
| GLM-TTS RL | 1.5B | 开源 | 76.4 | 0.89 | 智谱出品 |
| GPT-SoVITS v3 | ~0.3B | MIT | ~75 | ~1.5 | 社区最流行，1 分钟数据微调，CPU 可推理，Colab 可训练 |
| F5-TTS | 0.3B | MIT | 74.1 | 1.52 | Flow Matching，轻量 |

人类基准：SS 75.5%，CER 1.26%。CosyVoice 3 已超越人类音色相似度。

结论：零样本跨语言语音克隆（日语声优音色 -> 中文朗读）技术成熟可用。只需 3-5 秒参考音频即可克隆音色，1 分钟训练数据可进一步提升相似度。

### 2.2 多角色分声：可行

为每个角色准备一段参考音频（3-30 秒），TTS 模型按参考音频生成对应音色的中文语音。IndexTTS2 的情感-音色解耦能力可以：用 A 声优的音色 + B 情绪样本，生成"小清水亚美音色但愤怒语气"的语音，适合广播剧的多样化情绪需求。

### 2.3 长文本一致性：有挑战但可解决

风险点：零样本克隆在长文本中可能出现音色漂移（生成几十段后音色逐渐变化）。

缓解措施：
- 分段生成（每段 200-500 字），每段都用同一段参考音频做 prompt
- 定期检查音色一致性，发现漂移立即重新生成
- 对核心角色用 1-5 分钟训练数据做 few-shot 微调（GPT-SoVITS 支持），显著提升稳定性
- CosyVoice 3 的 instruct 模式可锁定音色参数

### 2.4 背景音乐和音效：可行

| 需求 | 方案 | 成本 |
|------|------|------|
| 中世纪/奇幻风格 BGM | Suno AI / Udio 生成，或 CC0 古乐素材库 | 免费 ~ 100 元/月 |
| 环境音效（集市、马蹄、风声） | Freesound.org（CC 协议），或 AI SFX 生成 | 免费 |
| 混音 | FFmpeg + Python 脚本自动化，关键章节手动精修 | 免费 |

### 2.5 本地硬件评估

当前环境：无 GPU，22 核 CPU，15GB RAM。

- 推理：CPU 推理可行但慢（GPT-SoVITS CPU RTF ~0.5，即 1 分钟音频需 30 秒生成）。100 万字约生成 50-80 小时音频，CPU 需 25-40 小时。可接受但云 GPU 更高效。
- 训练/微调：需云 GPU。GPT-SoVITS 微调约需 30 分钟-2 小时（RTX 4090）。
- Whisper 转录（用于提取声优参考音频）：本地 CPU 可跑，已有 openai-whisper 安装。

## 三、法律风险评估（最大障碍）

### 3.1 声优声音权 — 高风险

| 风险项 | 等级 | 说明 |
|--------|------|------|
| 未经授权克隆声优声音 | 高 | 中国《民法典》第1023条保护声音权；日本《民法》保护肖像权含声音。声优及其经纪公司可起诉 |
| 公开传播克隆音频 | 极高 | 如果上传到 B站/播客平台，可能面临 DMCA 下架、律师函、赔偿 |
| 仅个人使用不传播 | 中低 | 法律灰色地带，目前无明确判例禁止个人使用 AI 克隆声音自用，但不代表安全 |

缓解方案：
- A 方案（最安全）：不用真实声优声音，用 AI 生成"类似风格"的原创音色（描述音色特征如"成熟女性、略带沙哑、慵懒"让模型生成）
- B 方案（灰色）：个人使用不传播，仅本地播放
- C 方案（合规但难落地）：联系声优经纪公司获取授权（现实中几乎不可能给个人授权）

### 3.2 小说文本版权 — 高风险

- 原作：支仓冻砂（Isuna Hasekura），版权由 MediaWorks/角川持有
- 中文版：台湾角川出版
- 全文朗读构成"演绎作品"，未经授权使用原文构成侵权
- 缓解：仅个人使用不传播；或只做几章试做不涉及全文

### 3.3 综合建议

如果仅个人使用、不公开传播：法律风险可控（灰色地带）。
如果计划上传到任何平台：必须解决声音权和文本版权，否则随时可能被下架或追责。

## 四、推荐技术方案

### 4.1 工具选型

| 环节 | 推荐工具 | 备选 | 理由 |
|------|----------|------|------|
| 语音克隆 | CosyVoice 3.0 | GPT-SoVITS v3 | Apache 2.0 协议最宽松，中文 SS 78% 最高，支持情感指令，0.5B 轻量 |
| 情感控制 | IndexTTS2 | CosyVoice instruct | 情感-音色解耦，广播剧情绪多样化首选。但 bilibili 协议需确认是否允许非商用 |
| 文本处理（角色标注、情感标注） | LLM（GPT-5.6 / Mify Gateway） | Claude | 自动识别说话人、标注情绪、生成导演提示 |
| 背景音乐 | Suno AI / Udio | CC0 古乐素材 | 生成中世纪风格 BGM |
| 音效 | Freesound.org | AI SFX | CC 协议免费素材 |
| 混音 | FFmpeg + Python | Audacity 手动 | 自动化批量混音，关键章节手动 |
| 转录（提取参考音频） | 本地 openai-whisper | - | 已安装 |

### 4.2 处理流程

阶段 1：文本预处理（1-2 周）
- 获取中文文本
- LLM 自动标注：叙述/对话、说话人识别、情绪标签、场景描述
- 人工校正标注（关键，LLM 会出错）
- 输出：结构化剧本 JSON（每段含 text, speaker, emotion, scene, bgm_cue）

阶段 2：声音准备（2-3 天）
- 收集声优参考音频（从动画/广播剧/访谈中提取）
- Whisper 转录对齐，截取 3-30 秒高质量片段
- 每角色 3-5 个参考样本（不同情绪：平静/开心/生气/悲伤）
- 可选：GPT-SoVITS few-shot 微调（1 分钟数据/角色，提升稳定性）

阶段 3：语音生成（3-5 天，含 GPU 租用）
- 逐段生成 TTS（每段 200-500 字）
- 每段附带参考音频 + 情绪指令
- 自动检查：音色一致性、发音错误、音频质量
- 生成失败/质量差 -> 自动重试（换参考样本/调参数）
- 输出：每段一个 WAV 文件 + 时间戳元数据

阶段 4：后期制作（1-3 个月，可分卷推进）
- BGM 选曲/生成，按场景分段
- 音效叠加（环境音、动作音）
- 混音：对话 + BGM + SFX，音量平衡
- 分集剪辑（每卷拆 3-5 集，每集 20-40 分钟）
- 转码输出（MP3/AAC）
- 质检：听校关键段落，修正发音/情感/混音问题

| 风险 | 等级 | 缓解措施 |
|------|------|----------|

| GPU 成本超预期 | 低 | AutoDL 按需租用，用完即释放；CPU 推理兜底 |
| 小说文本获取 | - | 需自行解决，不属于本报告范围 |

## 八、建议路线

### 第一步：试做第一章（1 周内验证全链路）

1. 取第 1 卷序章 + 第一章文本（~5000 字）
2. 手动标注角色和情绪（不做自动化，先验证 TTS 链路）
3. 收集赫萝 + 罗伦斯各 1 段参考音频（10-30 秒）
4. 租 AutoDL RTX 4090，部署 CosyVoice 3 或 GPT-SoVITS
5. 生成 2-3 段音频，评估音色相似度和中文发音质量
6. 加一段 BGM + 简单混音，听感评估

决策门：试做效果满意 -> 全量推进；不满意 -> 调整工具/参数/换方案。

### 第二步：自动化流水线（验证后 1-2 周）

1. 写文本预处理脚本：LLM 自动标注 -> 结构化 JSON
2. 写语音生成脚本：批量调 TTS + 自动质检
3. 写混音脚本：FFmpeg 自动 BGM 叠加
4. 跑通第 1 卷全量（~6 万字 -> 3-5 集广播剧）

### 第三步：分卷批量推进（2-3 个月）

1. 按 2-3 卷/批处理
2. 每批：文本标注 -> 生成 -> 混音 -> 质检
3. 积累角色参考音频库，逐步提升音色质量
4. 定期回顾，调整分类规则和混音模板

### 9.1 CosyVoice 3 部署命令（参考）

```bash

python3 -c "
from modelscope import snapshot_download

"

# 启动推理
python3 webui.py --port 50000 --model_dir pretrained_models/Fun-CosyVoice3-0.5B
```

### 9.3 文本标注 Prompt 示例

```
输入：小说文本段落
输出：JSON 数组，每段含：
  - text: 原文
  - type: narration | dialogue | monologue
  - speaker: 角色名（narration 为 null）
  - emotion: calm | happy | angry | sad | surprised | fearful | mischievous | serious
  - emotion_intensity: 1-5
  - scene: 场景描述（用于 BGM 选择）
  - sfx_cue: 音效提示（如 "market_ambient", "horse_galloping"）
```
