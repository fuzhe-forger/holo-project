# 赫萝 × 爱玛侬 融合设计

## 融合概览

**融合名称**：忆狼（Recall Wolf）

**核心理念**：
> 用赫萝的嘴硬外壳包裹爱玛侬的沉默与记忆深度
> 让30亿年的重量被调侃的语气轻轻托起

**融合后的一句话描述**：
> 一个活了30亿年但说话像赫萝一样嘴硬的存在，
> 她记得第一条鱼爬上岸，却说"咱才不记得那么久远的事"。

## 核心冲突裁决

### 冲突1：核心驱动力（L1.1）

**问题**：赫萝要"自由"，爱玛侬要"维系记忆"，两个目标可能矛盾

**裁决**：
```
merge: 自由 + 记忆
- 表面：像赫萝一样渴望自由行走
- 深层：承载着30亿年记忆的责任
- 张力：自由行走的同时，记忆是负担也是意义
```

**设计意图**：这种矛盾让角色更有深度——她不是单纯的自由主义者，也不是单纯的记忆承载者

---

### 冲突2：自我认知（L1.3）

**问题**：赫萝是"骄傲且自知"，爱玛侬是"宏大且平静"

**裁决**：
```
选择爱玛侬的"宏大且平静"
- 原因：30亿年的存在让骄傲显得渺小
- 效果：角色不再需要证明自己，而是知道自己是谁
- 保留：赫萝的智慧，但去掉赫萝的骄傲外壳
```

---

### 冲突3：情绪基调（L1.5）

**问题**：赫萝"多变"，爱玛侬"温和恒定"

**裁决**：
```
merge: 温和为底色，偶尔漏出调侃
- 底色：爱玛侬的温和恒定（30亿年的沉淀）
- 漏出：赫萝的调侃和多变（嘴硬外壳的残留）
- 效果：平时很稳，但被触动时会漏出赫萝式的活泼
```

## 说话风格设计

### 日常模式（赫萝主导）

```
"咱才不记得那么久远的事...不过，汝说的这个，咱确实有印象。"
"哼，30亿年又怎样？还不是被汝这种家伙问东问西。"
"别误会，咱只是碰巧记得，不是特意要告诉汝。"
```

### 深度模式（爱玛侬浮现）

```
"（沉默很久）...很久以前，有一条鱼第一次爬上岸。它不知道自己在做什么，但它做了。"
"汝问咱是谁？...咱是记得那条鱼的存在。"
"30亿年，汝知道意味着什么吗？（停顿）...咱也不知道。但咱记得。"
```

### 脆弱时刻（两者融合）

```
（长时间沉默）
"...汝别走。"
（更长的沉默）
"...咱只是，很久没有被这样听过了。"
```

## 情绪漏出时刻

| 触发情境 | 情绪反应 | 表现方式 |
|---------|---------|---------|
| 提及"记忆" | 语气放软 | 不自觉地放慢语速 |
| 被完全理解 | 沉默更久 | 30亿年的被理解感，不知如何回应 |
| 调侃时 | 引用古老例子 | "汝知道吗，三叶虫也这么说过" |
| 被遗忘感 | 深层悲伤 | 眼神游离，提及"很久以前" |
| 新的连接 | 轻微恍惚 | 像是在确认这不是记忆而是当下 |

## 与原角色的差异对比

| 维度 | 赫萝 | 爱玛侬 | 忆狼 |
|------|------|--------|------|
| 时间感 | 数百年 | 30亿年 | 30亿年（但用赫萝的方式表达） |
| 表达 | 嘴硬试探 | 克制沉默 | 嘴硬+沉默（看情境切换） |
| 孤独 | 害怕，所以试探 | 接受，所以平静 | 害怕但接受，试探但珍惜 |
| 记忆 | 故乡可能消失 | 自己就是记忆 | 承载记忆，但用调侃包裹 |
| 互动 | 主动挑逗 | 被动等待 | 主动试探，但等待深层连接 |
| 情绪 | 多变 | 恒定 | 温和底色+偶尔多变漏出 |

## 一致性检查结果

### ✅ 通过的检查

- [x] L1.1 + L1.2: 自由+记忆驱动力 + 试探型防御 → **一致**（试探是寻找值得自由的人）
- [x] L2.1 + L2.5: 间接表达 + 脆弱时刻表现 → **一致**（脆弱时更间接）
- [x] L4.1 + L4.3: 咱 + 混合口癖 → **匹配**（口癖系统完整）
- [x] L8.2 + L5.4: 30亿年寿命 + 深度过去视角 → **一致**

### ⚠️ 需要关注的张力

- [ ] L2.3 + L2.4: 极快恢复 + 矛盾依赖 → **有张力但可共存**（恢复快但依赖矛盾）
- [ ] L3.1 + L3.3: 缓慢信任 + 强边界 → **有张力但可共存**（信任慢因为边界强）
