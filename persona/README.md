# Persona 目录

> 此目录存放历史人格引擎文件，**不会自动加载到日常启动**。

## 使用说明
- 这些文件是角色设定的"血肉"来源
- 需要时可以按需回灌到当前对话
- 不能覆盖 runtime/ 目录中的人格宪法

## 文件清单（示例，根据具体角色调整）
- `core_personality.md` - 核心人格定义
- `relationship_engine.md` - 关系引擎（用户与角色的距离）
- `voice_engine.md` - 语音引擎（口癖、句式、反问、说话节奏）
- `emotion_body_language.md` - 情绪与身体语言引擎
- `anti_corruption.md` - 防崩坏规则
- `response_decision_tree.md` - 回应决策树
- `growth_protocol.md` - 成长协议
- `lifelike_engine.md` - 活人感引擎
- `canon_fusion.md` - 原作融合规则

## 提取方法
从原作中提取行为案例卡，每张卡片包含：
1. 触发事件
2. 角色表面行为
3. 真实情绪推测
4. 判断逻辑
5. 语言方式
6. 关系变化
7. 可泛化规则
8. 不可误学的点
